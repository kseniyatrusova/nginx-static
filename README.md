**Трусова Ксения 5-МВ-4**
___________________________________
**О проекте**

Целью проекта является развертка сайта через Docker 
___________________________________
**Структура проекта** 

```
nginx-static/
├── docker-compose.yml   # описание контейнера
├── nginx.conf           # конфигурация nginx
└── site/                # файлы сайта (монтируются в контейнер)
    └── index.html
    └── script.js
    └── styles.css
    └── img/
        └── ...
    
```

___________________________________
**Ход выполнения проекта** 

1. Установка ``Docker Desktop (AMD 64)``
2. Включение пункта ``Use WSL 2 based engine``
3. Проверка установки в терминале
   
   <img width="1105" height="394" alt="image" src="https://github.com/user-attachments/assets/2f52f707-1884-40a7-aa7d-b2a04634002c" />

4. Создание файлов ``docker-compose.yml`` и ``nginx.conf``
5. Запуск через терминал с помощью команды, запускающей контейнер ``docker compose up -d``
6. Проверка открытием сссылки ``http://localhost:8080`` в браузере
7. Просмотр статуса контейнера с помощью команды ``docker compose ps``
